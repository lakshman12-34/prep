# 00 · Which companies hire freshers in large numbers? (verified edition)

Checked on 3 Oct 2026. [← Back to README](README.md)

> **The rule for this file:** a hiring number is listed only if it comes from:
> - **the company itself:** its annual report, results call, investor release or official page; or
> - **an established news outlet quoting a named company official.**
>
> If neither source gives a number, the file says **Not published**. Numbers from prep sites, job-listing sites or blogs are not used.
>
> This replaces the first version of this file. That version used blog numbers, and some of them were wrong (see section 6).
